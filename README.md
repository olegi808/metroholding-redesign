# Metro Avrasya Georgia — website redesign concept

Static prototype of a redesigned homepage for metroholding.ge (EN + KA) with placeholder pages.
This is a concept prototype, not the official company website.

- `index.html`, `*.html` — English version
- `ka/` — Georgian version
- `assets/` — shared styles and scripts
- `tools/build-stubs.sh` — regenerates placeholder pages from each language's `index.html`
